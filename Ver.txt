Archivos clave para arrancar (Fase 1)

1. utils/config.py: Define aquí desde el primer día el tamaño de bloque (ej. 4 * 1024 * 1024 bytes), el intervalo de Heartbeat (ej. 3 segundos) y el factor de replicación (ej. 2 copias por bloque).
2. certificates/generate_certs.sh: Un pequeño script usando openssl para generar certificados auto-firmados locales. Es vital para que el módulo ssl de Python funcione correctamente en las conexiones.
3. central_node/metadata_manager.py: El corazón del control de fallas. Debe ser capaz de escribir cada cambio en un archivo de texto plano (wal.log) antes de confirmarlo en memoria.
